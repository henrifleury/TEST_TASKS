# Анализ банковских отзывов — ML-решение

**Задача:** Быстро анализировать отзывы клиентов банка — определять, о каких продуктах пишут и с каким настроением.

**Особенности:**
- В одном отзыве может быть несколько продуктов
- Настроение к разным продуктам может быть разным
- Обработка 250 отзывов за 3 минуты

**Как работает:**

1. **Разбиваем отзыв на части**
   - Делим длинный отзыв на короткие фрагменты

2. **Анализируем каждую часть**
   - Две модели CatBoost проверяют каждый фрагмент:
     - Какие продукты упоминаются
     - Какое настроение (положительное/отрицательное)

3. **Объединяем результаты**
   - Специальная модель (1D CNN) смотрит на все фрагменты вместе
   - Выдает окончательную классификацию для всего отзыва

**Результат:**
Система понимает сложные отзывы, где клиент хвалит один продукт, но критикует другой, и делает это быстро.
